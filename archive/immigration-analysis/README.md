# Original immigration analysis

Preserved copy of the original Artfuldata analysis and collateral, before the portfolio website was introduced. The original root files are retained as well.

The script analyses `Unauthorized Dataset_DHS_Modified.xlsx` and produces static charts and two interactive Sankey pages in `plots/`.

Run from this directory with Python and pandas, numpy, matplotlib, and openpyxl installed:

```sh
python3 unauthorized_eda.py
```

The JPGs are the existing Sankey collateral. This archive is not included in the website deployment.
